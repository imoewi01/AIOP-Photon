The AI Optimized Polarization project has a goal of using a machine learning or reinforcement learning agent to automatically adjust some of our experimetanl controls. The main focus is on our photon beam system.

Our experiment uses a photon beam that is produced by an electron beam hitting a diamond. The diamond is held on a goniometer - a mechanical device that allows us to make millidegree size changes to the pitch, roll, and yaw of the diamond. By adjusting the pitch and yaw directions through small millidegree adjustments called "nudges", we can change the energy of the photon beam we see.

The goal of this project is to ensure the photon beam energy is never more than 1% from its desired value. This requires understanding how the electron beam parameters impact the photon beam parameters, as well as developing a simulation model for training the agent.
